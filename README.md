# pairwise-channelmix

## 题面（可直接粘贴）

声道矩阵混音。约束：单位矩阵原样、矩阵维度校验；必须实现下混响度归一（简化 BS.1770）与削波保护；同一输入两次处理结果一致且无爆音（相邻样本差有上界）；100 万样本不超过 300 ms；并发安全；非法矩阵/声道数要报错。验收：python -m pytest tests -q -k mix。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 10 万样本耗时
- 并发
- 非有限样本
- 矩阵上限
- 声道数边界

## 运行方式

```bash
python -m pytest tests -q
```
